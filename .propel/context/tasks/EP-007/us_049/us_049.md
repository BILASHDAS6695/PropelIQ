# US-049: Document Management & Access Control

## Story

**As a** patient,
**I want** to manage my uploaded documents (view list, download, delete) with confidence that only authorized users can access them,
**So that** my clinical information remains private and under my control.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-007 |
| **Priority** | High |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Patient document list: filename, upload date, status, file size, actions
- [ ] Patient can download their own documents
- [ ] Patient can request deletion (soft delete → admin approval for permanent deletion)
- [ ] Staff can view any patient's documents (within their role scope)
- [ ] Admin can permanently delete documents (with reason)
- [ ] Document download generates time-limited signed URL (expires in 5 minutes)
- [ ] All access (view, download) logged in audit trail
- [ ] Deletion logged with: who deleted, when, reason, document metadata retained
- [ ] API: `GET /patients/{id}/documents`, `GET /documents/{id}/download`, `DELETE /documents/{id}`

## Edge Cases

- Patient downloads document while it's still processing → serve original file (not extracted text)
- Soft-deleted document → hidden from patient, visible to admin in "Deleted" filter
- Staff attempts to download document for patient outside their scope → 403
