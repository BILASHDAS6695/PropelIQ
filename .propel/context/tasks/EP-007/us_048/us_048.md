# US-048: Document Viewer & Entity Highlighting

## Story

**As a** healthcare provider,
**I want** to view uploaded documents with NER entities highlighted inline,
**So that** I can quickly locate diagnoses, medications, and procedures within the document.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-007 |
| **Priority** | High |
| **Story Points** | 4 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Document viewer displays extracted text with entity highlights (color-coded by type)
- [ ] Entity legend: DIAGNOSIS (red), MEDICATION (blue), PROCEDURE (green), LAB (purple), SYMPTOM (orange)
- [ ] Click entity → tooltip with: entity type, confidence score, related codes (if available)
- [ ] Toggle highlights on/off per entity type
- [ ] Original document viewable (PDF rendered in-browser, images displayed)
- [ ] Side-by-side view: original document left, extracted text with highlights right
- [ ] Entity summary panel: list of all detected entities grouped by type
- [ ] Low-confidence entities shown with dashed underline (vs solid for high confidence)
- [ ] Keyboard navigation between entities (Next/Previous entity shortcuts)

## Edge Cases

- Document with no entities → viewer still shows text, "No entities detected" message
- Very long document → virtualized scroll for performance
- PDF with multiple pages → page navigation with entity count per page
