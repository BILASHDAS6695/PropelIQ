# US-039: Staff Multi-Provider Calendar View

## Story

**As a** front-desk staff member,
**I want** to see a side-by-side calendar of multiple providers for a given day,
**So that** I can coordinate scheduling and quickly identify available providers.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-005 |
| **Priority** | Medium |
| **Story Points** | 3 |
| **MoSCoW** | Should Have |

## Acceptance Criteria

- [ ] Day view showing columns for each provider (max 5 side by side)
- [ ] Provider selector: checkboxes to include/exclude providers from view
- [ ] Time rows: 15-minute intervals from clinic open to close
- [ ] Appointments displayed as blocks spanning their duration
- [ ] Available slots shown as empty/light-colored cells
- [ ] Click empty slot → quick-book dialog (select patient, create appointment)
- [ ] Drag appointment between providers (staff only) for reassignment
- [ ] Blocked/unavailable slots shown with hatched pattern
- [ ] Print-friendly layout for daily schedule printout

## Edge Cases

- All providers selected (>5) → horizontal scroll, sticky time column
- Provider with no schedule for selected date → column shows "Not Available"
- Drag appointment to blocked slot → snap back with error tooltip
