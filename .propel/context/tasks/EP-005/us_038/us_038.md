# US-038: ICS Calendar Export

## Story

**As a** patient,
**I want** to export my appointments as .ics files to add to Google Calendar or Outlook,
**So that** my medical appointments appear alongside my other commitments.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-005 |
| **Priority** | Medium |
| **Story Points** | 2 |
| **MoSCoW** | Should Have |

## Acceptance Criteria

- [ ] "Add to Calendar" button on appointment confirmation and detail views
- [ ] Generates standard .ics file (iCalendar format RFC 5545)
- [ ] ICS contains: event title (provider + appointment type), start/end time, location (clinic address)
- [ ] ICS includes reminder alarm (1 hour before)
- [ ] Download triggered via browser (no server-side file storage)
- [ ] Bulk export: download all upcoming appointments as single .ics file
- [ ] ICS file does not contain sensitive medical information (no visit reason)

## Edge Cases

- Cancelled appointment export → not included in bulk export
- Rescheduled appointment → new ICS available, old one not auto-updated
- Mobile browser → .ics opens in native calendar app
