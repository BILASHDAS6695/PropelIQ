# US-037: Interactive Calendar View

## Story

**As a** patient,
**I want** a visual calendar showing my appointments with color-coded statuses,
**So that** I can easily see my schedule at a glance.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-005 |
| **Priority** | High |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Monthly calendar view with appointment indicators on booked days
- [ ] Weekly view showing appointments as time blocks
- [ ] Daily view with detailed appointment information
- [ ] Color coding: Scheduled (blue), Completed (green), Cancelled (red), NoShow (gray)
- [ ] Click appointment → detail panel with actions (cancel, reschedule, swap)
- [ ] Staff calendar: shows all patients for selected provider
- [ ] Patient calendar: shows only their own appointments
- [ ] Navigate between months/weeks with arrow buttons
- [ ] Today button to quickly return to current date
- [ ] Responsive: month view on desktop, list view on mobile

## Edge Cases

- Month with no appointments → empty calendar, "No appointments" indicator
- Day with >5 appointments (staff view) → show count badge, expand on click
- Timezone handling → all times displayed in clinic's local timezone
