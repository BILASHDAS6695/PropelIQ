# US-003: Python FastAPI AI Service Setup

## Story

**As a** developer,
**I want** a Python FastAPI project structured for AI processing services (OCR, NER, coding, intake NLP),
**So that** the AI sidecar is ready to receive processing requests from the .NET backend.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-TECH |
| **Priority** | Critical |
| **Story Points** | 2 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] FastAPI project created with router structure (extraction, coding, intake)
- [ ] Health check endpoint at `/health` returns 200 with service status
- [ ] Requirements.txt includes: fastapi, uvicorn, spacy, pytesseract, pymupdf
- [ ] Service layer skeleton with placeholder classes for OCR, NER, coding, intake NLP
- [ ] Internal API key authentication middleware configured
- [ ] Structured logging configured (JSON format)
- [ ] CORS disabled (internal-only service)
- [ ] Service starts successfully with `uvicorn app.main:app`
- [ ] Basic request/response models defined with Pydantic

## Technical Notes

- Python 3.11+
- Use Pydantic v2 for models
- No external AI API calls (all local processing per ADR-004)
- Service listens on port 8000 by default
