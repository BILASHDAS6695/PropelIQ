# US-002: Angular 17+ Project Setup with Standalone Components

## Story

**As a** developer,
**I want** an Angular 17+ project configured with standalone components, routing, and core services,
**So that** the frontend has a consistent foundation with modern Angular patterns ready for feature development.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-TECH |
| **Priority** | Critical |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Angular 17+ project created with standalone components architecture
- [ ] App shell layout with header, navigation sidebar, and content area
- [ ] Routing configured with lazy-loaded feature routes (booking, intake, clinical, admin, dashboard)
- [ ] Core module contains: AuthService (stub), JWT HttpInterceptor, global error handler
- [ ] Shared module contains: reusable UI components (loading spinner, toast notifications)
- [ ] Angular Material or PrimeNG installed and configured with a base theme
- [ ] Environment files configured for development and production API URLs
- [ ] `ng build --configuration production` produces optimized bundle
- [ ] ESLint + Prettier configured with Angular-specific rules
- [ ] Proxy config for local development API calls

## Technical Notes

- Use `provideRouter()` with `withComponentInputBinding()`
- Configure `provideHttpClient(withInterceptors([...]))`
- Use Angular signals where applicable for state
- TypeScript strict mode enabled
