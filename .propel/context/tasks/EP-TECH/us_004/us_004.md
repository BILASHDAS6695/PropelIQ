# US-004: Docker Compose Development Environment

## Story

**As a** developer,
**I want** a Docker Compose configuration that starts the entire local development stack with a single command,
**So that** any team member can run the full system locally without manual setup of individual services.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-TECH |
| **Priority** | High |
| **Story Points** | 2 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] `docker-compose.yml` defines services: api (.NET), web (Angular dev server), ai (Python), postgres, redis
- [ ] PostgreSQL container starts with initial database created
- [ ] Redis container starts with default configuration
- [ ] .NET API container builds and runs with hot-reload enabled
- [ ] Python AI service container builds and starts
- [ ] Angular dev server proxies API calls to the .NET container
- [ ] All services communicate via a shared Docker network
- [ ] Environment variables loaded from `.env` file
- [ ] `docker-compose up` starts all services within 60 seconds
- [ ] Health check dependencies ensure API waits for DB and Redis readiness

## Technical Notes

- Use multi-stage Dockerfiles for .NET and Python
- Angular can run natively (not containerized) with proxy for faster dev iteration
- Volume mounts for source code to enable hot-reload
- PostgreSQL data volume for persistence across restarts
