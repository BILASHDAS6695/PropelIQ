# US-005: GitHub Actions CI Pipeline

## Story

**As a** developer,
**I want** a GitHub Actions CI pipeline that automatically builds, tests, and lints all projects on every push,
**So that** code quality is enforced automatically and broken builds are caught before merge.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-TECH |
| **Priority** | High |
| **Story Points** | 2 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Workflow triggers on push to all branches and on pull requests to main
- [ ] .NET build step: restore, build, test (xUnit)
- [ ] Angular build step: install, lint (ESLint), build (production), test (Karma/Jest)
- [ ] Python build step: install dependencies, lint (ruff), type check (mypy)
- [ ] Pipeline fails if any step fails
- [ ] Test results published as workflow artifacts
- [ ] Build time under 10 minutes
- [ ] Caching configured for NuGet, npm, and pip packages
- [ ] Branch protection rules documented (require CI pass before merge)

## Technical Notes

- Use GitHub Actions free tier (public repos unlimited; private repos 2000 min/month)
- Matrix strategy not needed for Phase 1 (single target)
- SAST scanning can be added as a separate job later
