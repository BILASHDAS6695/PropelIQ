# US-018: Angular Auth Module & Route Guards

## Story

**As a** frontend developer,
**I want** an Angular authentication module with login/register forms, token management, and route guards,
**So that** users have a complete auth experience and unauthorized navigation is blocked client-side.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-001 |
| **Priority** | Critical |
| **Story Points** | 5 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Login page: email + password fields, submit button, "Register" link, error display
- [ ] Registration page: all fields from US-013, inline validation, success redirect to login
- [ ] JWT stored in memory (not localStorage/sessionStorage) for XSS protection
- [ ] HTTP interceptor attaches Bearer token to all API requests
- [ ] HTTP interceptor handles 401 → attempts token refresh → on failure redirects to login
- [ ] `AuthGuard` (canActivate) blocks unauthenticated navigation to protected routes
- [ ] `RoleGuard` (canActivate) blocks navigation based on user role
- [ ] Inactivity timer on frontend: warns user at 13 minutes, auto-logout at 15 minutes
- [ ] Auth state managed via NgRx Signal Store (isAuthenticated, user, role)
- [ ] "Forgot Password" link present (sends password reset email)
- [ ] All forms use Angular Reactive Forms with validation messages

## Edge Cases

- Browser refresh → token lost (memory-only) → redirect to login
- Multiple tabs → one logs out → other tabs detect on next API call
- Token refresh race condition → queue requests, refresh once
