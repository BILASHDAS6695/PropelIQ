# US-035: Notification Preferences Management

## Story

**As a** patient,
**I want** to configure which notifications I receive and through which channels,
**So that** I'm not overwhelmed with messages I don't need.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-004 |
| **Priority** | Low |
| **Story Points** | 2 |
| **MoSCoW** | Could Have |

## Acceptance Criteria

- [ ] Settings page: toggle email notifications per category (reminders, swap, general)
- [ ] Settings page: toggle in-app notifications per category
- [ ] Default preferences: all channels enabled for all categories
- [ ] Preferences stored in user profile (JSONB column)
- [ ] Notification service checks preferences before sending
- [ ] Critical notifications (security: lockout, password expiry) cannot be disabled
- [ ] Preferences API: `GET/PUT /users/{id}/notification-preferences`
- [ ] Changes take effect immediately (no restart needed)

## Edge Cases

- User disables all email notifications → in-app still active
- User disables all notifications → security notifications still delivered
- Preference data migration for new notification types → default to enabled
