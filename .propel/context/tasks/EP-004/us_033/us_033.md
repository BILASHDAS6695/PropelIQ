# US-033: Appointment Reminder Scheduling

## Story

**As a** patient,
**I want** to receive reminders 24 hours and 2 hours before my appointment,
**So that** I don't forget my scheduled visits.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-004 |
| **Priority** | High |
| **Story Points** | 2 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] When appointment is booked, two Hangfire jobs scheduled: 24h before and 2h before
- [ ] Reminder email includes: provider name, date, time, location, "Cancel" link
- [ ] If appointment cancelled before reminder fires → job removed from queue
- [ ] If appointment rescheduled → old reminder jobs deleted, new ones scheduled
- [ ] Reminder not sent if appointment already completed or no-show
- [ ] Reminder job idempotent (safe to execute multiple times)
- [ ] Admin configurable reminder intervals (default: 24h + 2h)

## Edge Cases

- Appointment booked <2h from now → only send immediate confirmation, skip reminders
- Appointment booked <24h from now → skip 24h reminder, send 2h reminder
- Server restart → Hangfire persists jobs, no reminders lost
