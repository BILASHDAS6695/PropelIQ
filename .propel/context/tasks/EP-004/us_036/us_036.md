# US-036: PDF Report Generation (Appointment Summary)

## Story

**As a** patient,
**I want** to download a PDF summary of my appointment history,
**So that** I have a printable record of my visits for insurance or personal reference.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-004 |
| **Priority** | Low |
| **Story Points** | 2 |
| **MoSCoW** | Could Have |

## Acceptance Criteria

- [ ] PDF generated using QuestPDF library
- [ ] Report includes: patient name, appointment list (date, provider, status, visit reason)
- [ ] Report header: clinic name, generation date, patient name
- [ ] Report filtered by date range (default: last 12 months)
- [ ] PDF generated on-demand via API endpoint: `GET /patients/{id}/appointments/pdf?from=&to=`
- [ ] Generated asynchronously via Hangfire if >50 appointments, returns download link
- [ ] PDF download link expires after 1 hour
- [ ] Patient can only generate their own report; staff can generate for any patient

## Edge Cases

- No appointments in range → PDF with "No appointments found" message
- Very large report (500+ appointments) → paginated PDF, max 100 per run
- Concurrent generation requests → deduplicate, return same link
