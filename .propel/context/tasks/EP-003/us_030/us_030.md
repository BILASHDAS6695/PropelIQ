# US-030: Staff Swap Mediation & Override

## Story

**As a** staff member,
**I want** to view all pending swap requests and mediate or override if needed,
**So that** scheduling conflicts from swaps are resolved and clinic flow is maintained.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-003 |
| **Priority** | Low |
| **Story Points** | 2 |
| **MoSCoW** | Could Have |

## Acceptance Criteria

- [ ] Staff dashboard shows all pending swap requests (with both patient names visible to staff)
- [ ] Staff can force-approve a swap (bypasses target patient acceptance)
- [ ] Staff can force-decline a swap (with reason)
- [ ] Staff can initiate a three-way swap (manual reassignment of slots)
- [ ] All staff override actions require a reason text
- [ ] Override actions logged in audit trail with staff ID and reason
- [ ] Patients notified of staff-mediated outcomes

## Edge Cases

- Staff approves swap for deactivated patient → validation error
- Staff overrides already-expired swap → validation error
- Multiple staff try to mediate same swap → optimistic concurrency check
