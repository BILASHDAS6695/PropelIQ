# US-028: Slot Swap Request Initiation

## Story

**As a** patient,
**I want** to request a time swap with another patient who has a slot I prefer,
**So that** I can get a more convenient appointment time without cancelling.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-003 |
| **Priority** | Medium |
| **Story Points** | 3 |
| **MoSCoW** | Should Have |

## Acceptance Criteria

- [ ] Patient views list of other patients' booked slots (same provider, anonymized: shows only time)
- [ ] Patient selects desired slot and initiates swap request
- [ ] Swap request created with status "Pending" containing: requester, target slot, offered slot
- [ ] Target patient NOT identified to requester (privacy)
- [ ] Requester can cancel pending swap request
- [ ] Only one active swap request per appointment allowed
- [ ] Swap request expires after 24 hours if no response
- [ ] Audit log entry for swap request creation

## Edge Cases

- Target slot gets cancelled while swap is pending → swap auto-declined
- Requester cancels their appointment while swap pending → swap auto-cancelled
- Patient tries to swap with their own appointment → validation error
