# US-031: Angular Slot Swap UI

## Story

**As a** patient,
**I want** a visual interface to browse swappable slots, initiate swaps, and respond to requests,
**So that** I can manage slot swaps without staff assistance.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-003 |
| **Priority** | Medium |
| **Story Points** | 3 |
| **MoSCoW** | Should Have |

## Acceptance Criteria

- [ ] "Swap Slot" button on appointment detail for eligible appointments
- [ ] Swap browser: list of available slots for same provider (anonymized, time only)
- [ ] Swap request confirmation dialog: "Offer your [time] for [selected time]?"
- [ ] Incoming swap requests shown in notification panel with Accept/Decline buttons
- [ ] Swap history visible in appointment detail (requested, accepted, declined)
- [ ] Real-time notification badge when new swap request received (SignalR)
- [ ] Loading/error states for swap operations
- [ ] Mobile-responsive swap interface

## Edge Cases

- No swappable slots available → "No swap options available" message
- Swap request expired while viewing → "This request has expired" on action attempt
- SignalR disconnected → fall back to poll on page focus
