# US-021: Walk-In Appointment Registration

## Story

**As a** front-desk staff member,
**I want** to register walk-in patients and add them to the queue,
**So that** unscheduled patients are tracked and served in order.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-002 |
| **Priority** | High |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Staff can create walk-in appointment (patient, provider, visit reason)
- [ ] Walk-in appointment gets status "WalkIn" and queue position assigned
- [ ] Queue position calculated as: last position for that provider today + 1
- [ ] Walk-in appointment does not consume a pre-defined slot
- [ ] If patient not in system, staff can quick-create patient profile (name, phone, DOB)
- [ ] Walk-in marked with arrival time (auto-set to current time)
- [ ] Walk-in visible in provider's daily queue alongside scheduled patients
- [ ] Audit log entry created for walk-in registration

## Edge Cases

- Walk-in for provider with no scheduled patients today → first in queue
- Same patient walks in twice → allowed (different appointments)
- Staff registers walk-in for non-existent provider → validation error
