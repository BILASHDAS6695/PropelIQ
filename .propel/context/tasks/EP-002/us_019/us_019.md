# US-019: Provider Schedule & Slot Configuration

## Story

**As a** clinic administrator,
**I want** to configure provider schedules with available time slots,
**So that** patients can only book appointments during defined availability windows.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-002 |
| **Priority** | Critical |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Admin can define recurring weekly schedule per provider (day + start/end time)
- [ ] Default slot duration: 30 minutes (configurable per provider)
- [ ] Admin can mark specific dates as unavailable (vacation, holidays)
- [ ] System auto-generates individual appointment slots from schedule rules
- [ ] Slots generated for next 90 days (rolling window)
- [ ] Each slot has: providerId, date, startTime, endTime, status (Available/Booked/Blocked)
- [ ] Schedule changes do not affect already-booked slots
- [ ] API: `GET /providers/{id}/slots?date={date}` returns available slots

## Edge Cases

- Overlapping schedule rules → reject at creation time
- Schedule change mid-day → only future unbooked slots affected
- Provider with no schedule → returns empty availability
