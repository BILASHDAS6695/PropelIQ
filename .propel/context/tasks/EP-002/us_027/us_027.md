# US-027: Angular Booking UI Components

## Story

**As a** patient,
**I want** an intuitive booking interface with provider selection, calendar view, and confirmation,
**So that** I can easily find and book appointments without confusion.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-002 |
| **Priority** | Critical |
| **Story Points** | 5 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Provider list component: card layout with name, specialty, photo placeholder, next available date
- [ ] Provider filter: by specialty (dropdown), by name (search)
- [ ] Calendar component: month view with available/unavailable days highlighted
- [ ] Slot picker: available time slots for selected date as clickable chips
- [ ] Booking form: visit reason (textarea), confirm button, cancel button
- [ ] Confirmation view: appointment summary with "Add to Calendar" link (.ics download)
- [ ] My Appointments page: list of upcoming and past appointments with status badges
- [ ] Cancel/reschedule buttons on upcoming appointments
- [ ] Responsive design: mobile-first, functional on 320px width
- [ ] Loading states: skeleton loaders for provider list and slot fetch
- [ ] Error states: friendly messages for API failures

## Edge Cases

- No providers available for selected specialty → "No providers found" message
- All slots booked for selected date → "No slots available, try another date"
- Network error during booking → "Booking failed, please try again" with retry button
