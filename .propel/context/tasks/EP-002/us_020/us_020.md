# US-020: Patient Appointment Booking

## Story

**As a** patient,
**I want** to select a provider, view available slots, and book an appointment,
**So that** I can schedule a visit at a convenient time without calling the clinic.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-002 |
| **Priority** | Critical |
| **Story Points** | 5 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Patient selects provider from list (filtered by specialty optional)
- [ ] Available slots displayed for selected provider and date range
- [ ] Patient selects a slot and provides visit reason (free text, max 500 chars)
- [ ] On booking: slot status → "Booked", Appointment created with status "Scheduled"
- [ ] Slot locked during booking (optimistic concurrency with version check)
- [ ] Confirmation displayed with: provider name, date, time, appointment ID
- [ ] Confirmation email sent to patient (via notification service)
- [ ] Booking creates audit log entry
- [ ] API response time < 500ms for slot listing
- [ ] Patient can only have one active appointment per provider per day

## Edge Cases

- Two patients book same slot simultaneously → first wins, second gets "Slot no longer available"
- Patient books then immediately navigates away → booking committed
- Patient with expired insurance → booking still allowed (insurance verification is separate)
