# US-024: Provider Daily Queue Dashboard

## Story

**As a** healthcare provider,
**I want** to see my daily appointment queue with real-time updates,
**So that** I can plan my day and know when patients are ready.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-002 |
| **Priority** | High |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Dashboard shows all appointments for selected date (default: today)
- [ ] Each entry shows: patient name, time, status (Scheduled/Arrived/InProgress/Completed), visit reason
- [ ] Entries sorted by: Arrived first (by arrival time), then Scheduled (by slot time), then Walk-ins (by queue position)
- [ ] Real-time updates via SignalR when: patient arrives, status changes, walk-in added
- [ ] Provider can change appointment status: Arrived → InProgress → Completed
- [ ] Color coding: Scheduled (gray), Arrived (blue), InProgress (green), Late (orange)
- [ ] Queue count summary at top: "3 waiting, 1 in progress, 8 remaining"
- [ ] Click appointment → view patient summary (basic info, visit reason)

## Edge Cases

- No appointments today → "No appointments scheduled" message
- SignalR disconnection → auto-reconnect, show "Reconnecting..." indicator
- Large queue (>30 patients) → paginated or scrollable list
