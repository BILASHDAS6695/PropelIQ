# US-044: Angular Intake Chat & Form UI

## Story

**As a** patient,
**I want** a polished chat interface for conversational intake and a clean form interface for structured input,
**So that** I have a pleasant experience completing my pre-visit information.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-006 |
| **Priority** | High |
| **Story Points** | 4 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Chat interface: message bubbles (patient right, AI left), typing indicator, send button
- [ ] Chat messages rendered in real-time (streamed if possible, else on completion)
- [ ] Chat history scrollable, auto-scrolls to latest message
- [ ] Mode toggle (Chat/Form) prominently placed with clear labels
- [ ] Form interface: multi-step wizard with progress bar
- [ ] Quick-reply suggestions for common responses (e.g., "No known allergies")
- [ ] Submission confirmation: summary of provided data with "Edit" and "Submit" buttons
- [ ] "Save & Continue Later" button persists draft
- [ ] Accessible: keyboard navigable, screen reader compatible, WCAG 2.1 AA
- [ ] Mobile-optimized: chat takes full screen on small devices

## Edge Cases

- Long AI response → show incrementally or with "..." loading
- Network error during chat → "Message not sent, tap to retry"
- Patient accidentally closes tab → draft auto-saved every 30 seconds
