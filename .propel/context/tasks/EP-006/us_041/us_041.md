# US-041: Structured Intake Form Fallback

## Story

**As a** patient,
**I want** a traditional structured form option for intake if I prefer not to use the AI chat,
**So that** I can still complete pre-visit information in a familiar format.

## Details

| Field | Value |
|-------|-------|
| **Epic** | EP-006 |
| **Priority** | High |
| **Story Points** | 3 |
| **MoSCoW** | Must Have |

## Acceptance Criteria

- [ ] Toggle between "Chat" and "Form" mode at top of intake page
- [ ] Form sections: Chief Complaint, Symptoms, Duration/Severity, Medications, Allergies, Medical History
- [ ] Each section uses appropriate input types (text, dropdown, date, checkbox lists)
- [ ] Common medications and allergies offered as autocomplete suggestions
- [ ] Severity scale: 1-10 slider with descriptive labels
- [ ] Progress indicator showing completion percentage
- [ ] Save draft functionality (resume later before appointment)
- [ ] Form data maps to same structured output as conversational intake
- [ ] Validation: chief complaint required, other fields optional

## Edge Cases

- Switching from chat to form mid-intake → pre-fill form with already-gathered data
- Switching from form to chat mid-intake → AI acknowledges already-provided info
- Draft saved but appointment cancelled → draft purged after 7 days
