# apply-change

## Overview
As a Solution Architect, execute approved change requests through a controlled, artifact-aware implementation workflow that validates approvals, applies targeted updates across impacted artifacts, enforces traceability and quality gates, and produces an auditable implementation record.

## Execution
Call MCP tool:
    - ReadPrompt(name="apply-change", version="latest")

- Update ToDo list derived from the returned prompt instructions by readjusting the items.
